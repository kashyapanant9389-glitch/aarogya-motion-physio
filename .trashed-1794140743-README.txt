Publish on GitHub from an Android phone:
1. Open github.com in Chrome and sign in.
2. Tap + (top right) → New repository.
3. Repository name: aarogya-motion-physio
4. Set Public, then Create repository.
5. Open the repository → Add file → Upload files.
6. Upload index.html from this ZIP (extract the ZIP first if needed), then Commit changes.
7. Go to repository Settings → Pages.
8. Under Build and deployment, choose Deploy from a branch; branch main, folder /(root), then Save.
9. Wait a minute and open the URL shown on the Pages screen. It will look like:
   https://YOUR-USERNAME.github.io/aarogya-motion-physio/
